# LEARNING PLATFORM (frontend part)

## Запуск проетка

1. Установить [node.js](https://nodejs.org/en)
2. Находясь в корневой директории выполнить команду установки зависимостей проекта:

```js
npm i
```

3.1) Для разворачивании проекта в режиме разработки:

```js
npm run dev
```

3.2) Для сборки проекта для продакшен режима:

```js
npm rub build
```

Также будет необходим веб сервер (nginx) для раздачи статики
